# 🍱 FoodLoop

FoodLoop is a food donation platform developed using Python and Streamlit.

## Features

- 🔐 User Registration & Login
- 🍱 Donate Food
- 🏢 Request Food
- 🚚 Manage Pickup & Delivery
- 👨‍💼 Admin Dashboard

## Technologies Used

- Python
- Streamlit

## Project Structure

```
FOODLOOP/
│── app.py
│── pages/
│   ├── login.py
│   ├── donate.py
│   ├── requestfood.py
│   └── admin.py
```

## How to Run

```bash
pip install streamlit
streamlit run app.py
```
